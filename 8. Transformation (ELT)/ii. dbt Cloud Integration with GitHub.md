## **dbt** Cloud Integration with GitHub

* **dbt** → [Profile Name]
  - → Your Profile
    - Your Profile → **Personal Profile**
      - Linked Accounts
        - GitHub → **Link**
          - → Authorize dbt Cloud

        - GitHub → **Configure integration in GitHub**
          - Install dbt Cloud
            - All repositories / Only select repositories
            -  → Install
        
        - Sign in to dbt
        ...

* **dbt** → [Profile Name]
  - → Your Profile        
    - Settings → **Projects**
      - → [Project Name]
        - Project details → Edit
          - → Repository
            - Repository details → Edit
              - Disconnect → Confirm
          
          - Repository → **Configure Repository**
            - New repository
              - Add repository from → **GitHub**
              - Choose a repository → [Repository Name]

* **dbt** → Studio
  - → Restart Studio
  - → Initialize dbt project
  - → Commit to a new branch → Commit changes → Create a pull request on GitHub
* **GitHub** → Merge pull request
