## **Threading & Scheduling**

Threading lets a program do multiple tasks at once, like downloading files while updating a display. Scheduling runs tasks at specific times, like sending a daily report. These tools make your programs more efficient and automated. 

### The Time Module 
```py
import time 

print(time.time())  # Current time in seconds since the epoch 
time.sleep(5)  # Pause execution for 5 seconds 
```

### The DateTime Function 
```py
from datetime import datetime 

now = datetime.now() 

print(now.strftime("%Y-%m-%d %H:%M:%S")) 
```

### Python Threading 
```py
import threading 
import time 

def print_numbers(): 

    for i in range(5): 
        print(i) 
        time.sleep(1) 

thread = threading.Thread(target = print_numbers) 

thread.start()
thread.join() 
```

```py
import schedule 
import time 

def job(): 
    print("I'm working...") 

schedule.every(10).seconds.do(job) 
while True: 
    schedule.run_pending() 
    time.sleep(1) 
```

### Mini-Project: Periodic File Backup 

#### Reason

Regular backups prevent data loss. This script automates file backups at set intervals.

```py
import shutil 
import schedule 
import time 

def backup_file(source, destination): 
    shutil.copy(source, destination) 
    print(f"Backed up {source} to {destination}") 

# Schedule the backup every hour 
schedule.every().hour.do(backup_file, 'important.txt', 'backup/important.txt') 

while True: 
    schedule.run_pending() 
    time.sleep(1) 
```

#### Explanation 
This script copies a file to a backup directory every hour, ensuring data safety.
