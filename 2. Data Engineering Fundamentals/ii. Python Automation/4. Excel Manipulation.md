## **Excel Manipulation**

Excel is a popular tool for data analysis, but manual tasks like updating spreadsheets can be slow. Python’s openpyxl library automates these tasks, making it easy to read, write, and format Excel files. 

### Install `openpyxl`:
```
pip install openpyxl
```

### Creating a new Workbook from `openpyxl`
```py
from openpyxl import Workbook 

workbook = Workbook() 
sheet = workbook.active

# Writing on a cell and saving sheet
sheet['A1'] = 'Hello, world!' 
workbook.save('example.xlsx') 
```

### Reading Sheets and Cells from a previously saved Workbook
```py
from openpyxl import load_workbook 

workbook = load_workbook('example.xlsx') 
sheet = workbook['Sheet1']

print(sheet['A1'].value)  # 'Hello, world!'
```
* Accessing all items of a Column
    ```py
    for cell in sheet['A']: # Excel columns are alphabetical
        print(cell.value) 
    ```
* Accessing all items of a row 
    ```py
    for cell in sheet[1]: # Excel rows are numerical
        print(cell.value) 
    ```

### Setting Fonts and Formulas
```py
from openpyxl.styles import Font 

sheet['A1'].font = Font(bold=True) 
sheet['C1'] = 'SUM(A1:B1)'
```

### Merging Cells and Freezing Panes
```py
sheet.merge_cells('A1:B1') 
sheet.freeze_panes = 'A2' 
```

## Mini-Project: Generate Monthly Report 

### Reason 
Automating monthly report generation from Excel data saves time and reduces errors, especially for repetitive tasks. 
```py
from openpyxl import load_workbook 
from openpyxl.utils import get_column_letter 
from openpyxl.styles import Font 

def generate_monthly_report(input_file, output_file): 
    wb = load_workbook(input_file) 
    ws = wb['Data'] 

    # Assume data is in columns A to D, with headers in row 1 

    # Calculate totals for each column 
    totals = {} 

    for col in range(1, 5):  # Columns A to D 
        total = 0 

        for row in range(2, ws.max_row + 1): 
            cell = ws.cell(row=row, column=col) 

            if cell.value is not None: 
                total += cell.value 

        totals[get_column_letter(col)] = total    

    # Create a new sheet for the report 
    report_ws = wb.create_sheet(title='Monthly Report') 

    report_ws['A1'] = 'Monthly Totals' 
    report_ws['A1'].font = Font(bold=True) 
    
    row = 2 

    for col, total in totals.items(): 
        report_ws.cell(row=row, column=1).value = f'Total for {col}:' 
        report_ws.cell(row=row, column=2).value = total 
        row += 1 

    wb.save(output_file) 

# Example usage 
generate_monthly_report('data.xlsx', 'report.xlsx') 
```
### Explanation 
This script reads an Excel file, calculates column totals, and creates a new sheet with a formatted report.
