## **JSON Manipulation**

JSON is a simple format for storing and sharing data, like a digital notebook that both humans and computers can read. Python’s `json` module makes it easy to read and write JSON data, useful for APIs or data storage. 

**Read JSON**

```py
import json 
with open('data.json', 'r') as f: 
    data = json.load(f) 
print(data) 
```
**Write JSON** 
```py
data = {'name': 'John', 'age': 30, 'city': 'New York'} 

with open('data.json', 'w') as f: 
    json.dump(data, f, indent=4) 
```

### Mini-Project: Convert CSV to JSON 

**Reason**

Converting CSV data to JSON is common when preparing data for APIs or databases that use JSON.

```py
import csv 
import json 

def csv_to_json(csv_file, json_file): 
    data = [] 

    with open(csv_file, 'r') as f: 
        reader = csv.DictReader(f) 

        for row in reader: 
            data.append(row) 

    with open(json_file, 'w') as f: 
        json.dump(data, f, indent=4) 

# Example usage 
csv_to_json('data.csv', 'data.json') 
```


**Explanation**

This script reads a CSV file and converts each row into a JSON object, saving the result to a JSON file.
