## **Sending & Retrieving Emails**
Automating email tasks, like sending reports or checking inboxes, saves time and reduces manual errors.

### **EmailMessage** - Creating Email Header and Body
`EmailMessage` is the modern (Python 3.6+), preferred way to handle emails, it is automated unlike MIMEText, replaces the complex tree of MIME classes with a single, intuitive interface that handles headers, body, and attachments much more naturally.

```python
from email.message import EmailMessage
import mimetypes

def set_emailmessage(subject, from_email, to_email, body, html_path, attachment_path):

    # 1. Initialize the modern EmailMessage object
    msg = EmailMessage()

    # 2. Headers are set just like a dictionary
    msg['Subject'] = subject
    msg['From'] = from_email
    msg['To'] = to_email

    # 3. Set the main plain-text body
    msg.set_content(body)

    # Want to add an HTML version? Just add it as an alternative:
    with open(html_path, "r", encoding="utf-8") as f:
        html_content = f.read()
    msg.add_alternative(html_content, subtype='html')


    # Detect file type and add attachment
    ctype, encoding = mimetypes.guess_type(attachment_path)
    if ctype is None or encoding is not None:
        ctype = 'application/octet-stream'
    maintype, subtype = ctype.split('/', 1)

    with open(attachment_path, 'rb') as f:
        msg.add_attachment(
            f.read(),
            maintype=maintype,
            subtype=subtype,
            filename=attachment_path.split('/')[-1] # Grabs the actual filename
        )

    return msg
```

### SMTP Library
Sends email. Stands for **Simple Mail Transfer Protocol Library**
    
```py
import smtplib
from email.message import EmailMessage

def send_email(subject, to_email, body, html_file, attach_file): 
    from_email = "your_email@gmail.com" 
    password = "your_app_password"  # Note: Use a Gmail App Password, not your login password
    
    # Creating Email Header and Body by passing values as parameters of the previously defined function that uses EmailMessage
    message = set_emailmessage(subject, from_email, to_email,  body, html_file, attach_file)

    # 6. Use SMTP_SSL for port 465
    with smtplib.SMTP_SSL('smtp.gmail.com', 465) as server: 
        server.login(from_email, password) 
        # send_message is preferred over sendmail as it handles all the MIME/header conversions automatically
        server.send_message(message) 

# Example usage 
send_email("Test Subject", "recipient@example.com", "This is a modern test email", "index.html", "report.pdf")
```


### IMAP Library
Retrieves email. `policy=email.policy.default` ensures that even if the email was sent using old legacy tools like `MIMEText`, Python converts it into a modern `EmailMessage` object automatically.

```py
import imaplib 
import email 

def retrieve_emails(): 
    
    with imaplib.IMAP4_SSL('imap.gmail.com') as imap:
        imap.login('user@example.com', 'your-app-password')
        imap.select('INBOX')

        # Search for the latest email
        typ, data = imap.search(None, 'ALL')
        last_msg_id = data[0].split()[-1]

        # Fetch the raw bytes
        typ, msg_data = imap.fetch(last_msg_id, '(RFC822)')
        raw_bytes = msg_data[0][1]
        
        # CONVERSION: The modern built-in way to parse
        msg = email.message_from_bytes(raw_bytes, policy=email.policy.default)
        
        print(f"Subject: {msg['Subject']}")
        print(f"From: {msg['From']}")
        
        # Get the body text easily without manual decoding
        body = msg.get_content()
        print(f"Body: {body}")
        

 # Example usage e
retrieve_emails() 
```

Automating daily weather reports via email ensures you stay informed without manual effort.
